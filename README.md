# Laravel Job Portal

A production-ready job marketplace built with Laravel.
Live Demo https://livejobsbd.com/
## Features

- User authentication
- Employer dashboard
- Candidate dashboard
- Job posting
- Job applications
- Admin panel
- Role-based authorization
- Notifications
- Search & filtering

## Tech Stack

Laravel
PHP
MySQL
Blade
JavaScript
Bootstrap
